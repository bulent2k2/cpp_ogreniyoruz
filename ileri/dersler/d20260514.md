Elif ve Eren'in paylaştığı birkaç *C* sorusunu çözdük birlikte. Epey zor ve öğretici sorular. 

`struct` ve `union` hakkında
====

Soru 40
----

```c
struct {
    short s[5];  // noktalı virgülü unutmuşlar
    union {
        float y;
        long z;
    } u;
} t;
```

`short` 2 byte, `float` 4 byte, `long` 8 byte olduğuna göre `t` değişkeni (bellekte) ne kadar yer kaplar?
Hepsi `byte` olarak:
```
a) 22
b) 14
c) 18
d) 10
e) 20
```

Soru 49
----

```c
int main() {
    struct structt {
        char str[] = "damacana";
        int i = 1964;
    };
    struct structt *p;
    printf("%d ", p->i);
    printf("%d ", p->str);
}
```

Yukarıdaki kod parçasının çıktısı ne olur?
```
a) 1964
b) 1964 damacana
c) damacana
d) Derleyici hata verir ("Derleme zamanı hatası" diye tercüme etmişler)
e) Çalışırken hata verir ("Çalışma zamanı hatası)
```

Bit işlemleri ve eksi sayıların iki tabanında yazılması
====

Soru 49
----

```c
#include <stdio.h>
int main() {
    char a = (1<<7) - 1;
    a -= 32;
    printf("%d", ~a);
}
```

Yukarıdaki kod parçasının çıktısı ne olur?
```
a) -97
b) -161
c) 161
d) -96
e) hiçbiri
```

Soru 45
----

```c
int main() {
    unsigned int x = -1;
    int y = -1, z = 1; a = ~0;
    if (x == y) printf("F");
    if (x == z) printf("L");
    if (z == a) printf("B");
    if (x == a) printf("O");
    printf("T");
}
```

Yukarıdaki kod parçasının çıktısı ne olur?
```
a) FBOT
b) FOT
c) LT
d) LBOT
e) T
```

Harf dizileri ve adres değişkenleri
====

Soru 36
----
```c
#include <stdio.h>
int main() {
    char *s[] = { "knowledge", "is", "power" };
    char **p = s;
    printf("%s ", ++*p);
    printf("%s ", *p++);
    printf("%s ", ++*p);
    printf("\n");
}
```

Yukarıdaki kod parçasının çıktısı ne olur?
```
a) is power
b) nowledge nowledge s
c) is ower
d) nowledge knowledge is
e) Hiçbiri
```
